# Kimi Code package

The runtime provider is `acp:kimi-code` and the signing key ID is `tutti-kimi-code-release-v1`. Keep all package content declarative.

`icon.png` is the colored shared branded identity used on every Agent surface,
including the Provider Rail, conversation rows and headers, Message Center,
and mentions. Do not declare a `maskIcon`: Kimi Code intentionally preserves
its original branded icon instead of projecting it as a monochrome glyph.
